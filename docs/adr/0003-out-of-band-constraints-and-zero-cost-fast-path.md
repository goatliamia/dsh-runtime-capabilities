# ADR-0003：旁路约束与零额外成本快速路径

- 状态：accepted
- 日期：2026-08-28

## 背景

多路 DSH 对话需要遵守隐私、状态一致性、授权和文件边界，但把规则全部塞进提示词会增加上下文负担，影响模型表现，并可能增加每轮模型成本。依赖模型“自觉遵守”也无法提供可靠的硬保证。

## 决策

约束放在 AI 推理之外：

1. schema、SQLite 外键、Core 状态机和 API 输入检查负责硬约束；
2. Signal/Impact Preview/收件箱排序承载软约束，不改写每轮模型上下文；
3. 正常对话不触发额外模型调用、向量检索或远程服务；
4. 只在 session stop、插件错误、用户请求总结、派送和文件应用等明确边界触发校验；
5. 自动 session-stop 默认走本地摘要或使用宿主已经生成的摘要；额外模型摘要必须是显式策略；
6. Bridge 故障不阻塞普通 DSH 操作，只影响 Bridge 自己负责的派送或应用动作。

自动 session-stop 的 HTTP 传输失败返回 `skipped`，而不是让宿主会话失败；显式派送或文件应用仍然必须把错误呈现给用户。

## 结果

模型保持原有工作上下文和性能；多数操作没有新增 token 或网络成本；违规状态不能靠模型输出绕过；用户也不会因为同步机制而被迫改变正常工作方式。

## 复审条件

如果真实 DSH 宿主要求在每轮注入规则，先测量 token、延迟和质量变化，再决定是否做局部、按需提示；不得默认改成全局提示词。
